# Fluxa

Android RSS 阅读客户端，Kotlin、Compose、Material 3、Hilt、Room。保留紧凑的 Reeder Classic 阅读布局。
**本地 RSS 无需账号**；NewsBlur 是另一个可选入口，不需要 OAuth Client 或 API Key。

## 当前源码能力

### 本地 RSS

- 添加 HTTP/HTTPS RSS、Atom，或从网页发现明确声明的订阅候选；预览后才确认。爱范儿早报可单独订阅。
- 文件夹、来源别名、暂停、取消订阅和恢复；取消订阅不删除已有文章。
- 系统文件选择器导入/导出 OPML，浏览器分享后预览并保存网页。OPML 是订阅交换，不是完整备份。
- 按来源选择 RSS、提取全文或原网页。RSS 与全文独立保存；失败不覆盖 RSS。原网页仅由用户点击打开。
- RSS 正文随刷新保存；图片按网络策略与预算尽力内嵌保存。阅读 WebView 禁止远程加载、脚本和文件访问；不是所有图片都保证离线。
- 独立稍后读、收藏、阅读状态、段落摘录与笔记。笔记是整段选择，不是任意原生文字选区；重复段落数量或内容变化时保留未匹配笔记，不强行附着。
- 本地标题/正文搜索、全部/未读/收藏/稍后读/24 小时、来源排序、隐藏已读、保存搜索、保留/屏蔽规则及仅用于显示的链接去重。
- 阅读队列在打开时冻结，RSS/全文分别记忆位置；返回恢复列表定位。筛选日期当前采用 **UTC**，列表日期采用本地时区，两者可能相差一天；已有保存范围不自动迁移。

### 缓存与后台

“更多 → 本地 RSS 离线与后台”设置软容量 64/128/256/512 MiB、图片开关、仅 Wi-Fi、已读保护天数与独立后台刷新。
未读、近期或阅读时间未知、收藏、稍后读、保存网页、手动保留及文件夹保留均受保护。
超限时先清理旧已读图片和可选全文，**不删除 RSS 文字**；受保护内容可能使容量继续超出软上限。
取消保留不会立即清理。普通列表与阅读器不常驻显示缓存说明。

公开抓取是匿名、有界请求：拒绝 URL 凭据及 HTTPS 降级，Feed 上限 5 MiB/500 条，单篇 RSS 400 KB；
图片单图 1 MiB，每轮 24 MiB/80 次实际请求，含重定向。单篇内嵌正文约 1.4 MB。
本地后台尽力每小时刷新，跳过暂停/归档来源；系统可延迟或跳过，不能保证整点执行。
按源通知默认关闭，用户明确启用后仅发送新增文章摘要；首次导入安静，22:00–08:00 累积到后续刷新机会，不保证恰好一次送达。

### 本地 JSON 备份（本轮候选，待 root 验证）

“更多 → 本地备份与恢复”通过 SAF 创建/打开 JSON 文件。v1 格式只包含白名单本地模型：订阅、文件夹、别名、暂停/归档、模式、文章信息及标记、稍后读、笔记、离线保留与容量策略、来源显示与滑动偏好、保存搜索/规则，以及阅读设置、位置和冻结会话。

- 正文默认不包含；“包含 RSS 与已提取全文”和“另含已保存图片”分别显式选择。文件上限 32 MiB、5000 篇文章、500 个来源。原文和全文不混写；图片限 PNG/JPEG/GIF/WebP，检查 MIME 与签名，不下载图片。
- **不包含账号、凭据、认证数据库、私有偏好原始文件、通知启用状态或后台开关。** 不读取/复制偏好 `getAll()`。
- 打开文件后仅预览，列出版本、实际字节数、新增数量、已有文章及载荷范围；确认前没有数据库或设置写入，也不联网。
- 仅合并，无覆盖/删除模式。已有文章标记与设置优先；ID 必须与来源、GUID、网址和内容身份相符。支持已有合法的非 URL 派生旧本地 ID。
- 缺失文章可仅恢复标题、链接、摘要与标记，正文为空；阅读器明确说明未保存正文，可刷新订阅或打开原文。缺失全文不伪装成缓存命中。
- 完整校验失败不写入；资料库在预览后变化会拒绝旧确认。一个本地数据库事务提交；随后通过各设置存储的类型化合并单独保存，**不是跨存储完全原子**。设置失败有明确重试状态，不谎报完整成功。
- 文件选择/预览不跨进程恢复；系统回收后需重新选择。退出不撤回已提交文章；取消未确认预览保留原数据。撤销入口和设置失败的待重试载荷目前只保留于进程。

### 列表和阅读工具（本轮候选，待 root 验证）

“筛选与规则”设置紧凑/舒适、摘要、缩略图，复用已有封面，不改变阅读状态或冻结队列。
“列表滑动设置”支持全局与当前来源覆盖；来源未设置时继承全局。
浅滑可选已读、已读/未读或收藏；深滑选择不同动作，可用于本地稍后读。远程来源不调用虚构稍后读 API。
保持既有阈值、触摸距离、横纵仲裁、多指/边缘排除；松手只执行选中的一段，拖回取消。
长按/无障碍文章操作提供等价功能，图标目标 48dp。列表标记撤销使用捕获的绝对状态与本地版本，不盲目再次切换；回执只在进程内保留。

阅读器更多菜单提供真实 Android TextToSpeech 和 Android 12+ TranslationManager 入口，仅按需启动。
只列出设备实际报告已安装的离线语音/翻译能力，不自动下载模型，不使用收费 AI 或虚构成功结果。
后台/离开取消工作，翻译单独显示且不覆盖原文；缺少能力、超时或部分失败明确显示。
实际服务、音频和生命周期行为仍须设备验收；纯协调测试不是引擎验收。

图片查看器及原生 TalkBack 换篇目前仍是**未通过的设备验收门槛**。本轮有基于实际失败的原生手势确认和测试同步修复候选，但不能据源码称其已可用。

## NewsBlur（可选）

支持免费账号用户名/密码登录、订阅、阅读与收藏、离线绝对意图队列及可选后台同步。
密码不保存，会话使用 Android 加密存储。账号客户端仅 TLS、禁止重定向；公开 RSS 客户端支持用户明确输入的 HTTP，不使用账号 Cookie。
单账号缓存绑定首次登录用户名；真实账号联调仍需用户验收。免费账户的订阅启用/历史范围由 NewsBlur 决定。
旧 Inoreader 实现仅作历史兼容，不是可切换后端；旧认证数据不被本地备份或新后端读取/重放。

## 数据与版本

- 本地 `direct-rss.db` **v6**，显式追加迁移 v1→2→3→4→5→6：组织信息、全文/模式、本地版本、作者、独立稍后读与 `reader_notes`。
- `app/schemas/...DirectRssDatabase/1.json` 至 `5.json` 保留；v6 由 root 首批构建生成。本轮不改 schema，不使用破坏式 fallback。
- NewsBlur/历史 FluxaDatabase 仍为 v3；GitHub 收藏库使用独立数据库。
- 未知 schema 拒绝打开，避免静默删数据。软容量按正文 UTF-8 字节计算，不代表 SQLite 文件即时缩小。

登录页“GitHub 收藏 · 无需登录”或 RSS 更多菜单进入。公开用户名默认 `Vincent1993`，可切换独立本地库。
公开 Stars 分页导入、用途标签、搜索、每日推荐与浏览历史；无需 GitHub token 或 AI。
继续导入和重新导入保留手工整理，远端取消 Star 不删除本地记录。
私有 Stars、Discovery、Release 订阅尚未实现。
既有独立验收见 [GitHub 收藏库记录](docs/github-library-results-2026-10-08.md)。

## 构建

JDK 17，Android SDK platform **37.0** / build-tools **36.0.0**；compileSdk/targetSdk **37**，minSdk **26**。
Compose BOM 为工程已有的 **2026.09.00**，本轮未升级依赖或宣称使用“最新 Expressive”。
在被 git 忽略的 `local.properties` 配置 `sdk.dir`。

```sh
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug
```

Debug 包名 `com.fluxa.app.debug`，Preview `com.fluxa.app.preview`，Stable `com.fluxa.app`。
同渠道升级须保持签名，勿以卸载丢失缓存来解决签名冲突。
渠道、固定签名与 CI/发布流程见 [发布指南](docs/releases.md)、[贡献约定](CONTRIBUTING.md)。
当前 API37 的公开 HTTP manifest 配置不适用于未来 target38+；升级时需要审查 Network Security Config，不通过降级 SDK 或证书绕过解决。
